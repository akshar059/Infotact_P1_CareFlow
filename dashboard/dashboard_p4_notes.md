# Loopbacks & Outliers Analytics Report

## Overview
This document tracks the integration of the Power BI report (`CareFlow_Loopbacks_and_Outliers.pbix`) into the CareFlow clinical analytics pipeline.

## Key Analytics Included
- **Outlier Isolation:** Identifies clinical pathways with abnormally high transit and waiting times.
- **Loopback Analysis:** Maps recurring patient transitions between emergency, triage, and diagnostic departments to reduce process redundancy.
- **Performance Impact:** Provides actionable insights for optimizing hospital resource management and reducing bottleneck delays.
