# CareFlow: Clinical Pathway Process Mining

## Project Overview
CareFlow analyzes hospital patient journey event logs to understand activity sequences, waiting times, and workflow delays.

## Objectives
- Collect a suitable clinical event-log dataset.
- Clean and validate the data.
- Identify common patient pathways.
- Analyze patient journey duration and waiting times.
- Identify bottlenecks and repeated activities.
- Present findings using visualizations and a dashboard.

## Proposed Technologies
- Python
- Pandas
- PM4Py
- Matplotlib or Plotly
- Streamlit
- Git and GitHub

## Project Workflow
1. Dataset collection
2. Data preprocessing
3. Process mining
4. Exploratory data analysis
5. Visualization and dashboard integration
6. Testing and documentation

## Data Privacy
Use suitable public, de-identified, or synthetic data. Do not publish confidential patient information.
